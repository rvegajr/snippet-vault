# Snippet Vault

A local-first web app where developers save, tag, and instantly search code snippets — running entirely on their own machine.

## Prerequisites

- [Node.js](https://nodejs.org/) 20 or later

## Getting started

```bash
git clone https://github.com/rvegajr/snippet-vault.git
cd snippet-vault
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Build and start the development server |
| `npm run build` | Compile server and client to `dist/` |
| `npm test` | Run the test suite |
| `npm run lint` | Run ESLint |
| `npm run typecheck` | Run TypeScript type checking |
